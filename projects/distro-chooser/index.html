What is this?
#

This is a simple Linux Distro Chooser tool that I created to help people find the perfect Linux distribution for their needs. It is based on my personal experience and recommendations.

Try it out!
#

How does it work?
#

The tool asks you a series of questions about your preferences and needs, and based on your answers, it suggests 3 best Linux distributions for you. The questions are very simple.

Scoring System
#

Each distro has parameters like difficulty, stability, release cycle and gaming support, and based on your answers, the tool calculates the points for each distro and suggests the best ones for you.

Distro possibilities
#

Theres not many distros in the database, because I can only reccomend so much, because most distros are just copies of each other, so I only added the ones, that have the best community, and that I can personally reccomend with certain confidence.
