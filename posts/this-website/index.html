Making this website

📅 Published: Friday, January 23, 2026 📖 1 min read 📊 194 words 🏷️ Tags: webdev
A look into the process of making my personal website in Hugo with the Blowfish theme.

Making this website

I have made my first ever website when I was in 6th grade in primary school (I was 11). It was a very simple website made with, very coincidentally… Hugo!

How did I start?

Hugo was introduced to me by my brother, who already had some experience with it, so he set me up with a very basic template and I got to work. You can still find the website on GitHub. It’s actually my first ever GitHub repository!

My personal website journey

Over the years, I have made several versions of my personal website, each time using something else. Before I have made this specific website, I had a website made with HTML/CSS with a CSS framework called Bulma.io.

Why Hugo again?

This time, I said to myself, “Why not try Hugo again?”. It was pretty simple, and looking at it now, after all those years, It has come a long way, and the themes actually look pretty good.

What am I doing now?

So here I am, making my first blog on my new personal website, made with Hugo and the Blowfish theme, which you can check out here.
