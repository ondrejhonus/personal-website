👩‍💻 Who am I? 👩‍💻

Hey, im Ondřej Honus, a student software engineer! I mostly use C++ and Golang, but I also sometimes end up working with Python. My favourite project I’ve made is bubblegit, a TUI appliaction that makes using git easier and allows you to work with it without much knowledge of git.

Apart from thatm I LOVE to cook and bake (recipes here) and I also play guitar in my spare time.

📂 My proudest projects 📂

  • CPM – Terminal process manager! GitHub
  • BUBBLEGIT – Git command TUI tool GitHub
  • VEGE DREAMS – My vegetarian recipe book GitHub
