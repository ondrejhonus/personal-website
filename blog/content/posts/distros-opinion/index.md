### My rating of Linux distros

#### 1. Void Linux
> Void linux is #1 only because it doesn't use `systemd` as an init system... Okay also because of it's blazingly fast package manager... And customizability also >~<
> I don't know why, it might be because you build it to your needs, but I find it very snappy and comfortable to use. I for some reason really like it, and I can't really explain why.

.Pros:

- ✅ Fast package manager (XBPS), pretty reliable, has all the packages I need (I have some that weren't there from `flatpak`).

- ✅ Free from systemd, uses runit.

- ✅ Good status in the Linux community.

- ✅ It's DIY, so it can be whatever you make it.

Cons:
- ❌ Might be unstable, I'm not sure. It didnt break on me yet, but it's DIY so it might differ on your skill level.

- ❌ Not beginner friendly, not even a little bit.


#### 2. OpenSUSE Tumbleweed

> This one is honestly the best Linux distro I think you can use, by far. You have the goodness of rolling release with stability. It's literally the only good rolling release Linux distro you won't tear you hair out using.

Pros:

- ✅ It's incredibly stable. Before they publish any update, they test the software before publishing it. So it's far more stable than other rolling-release distros (like Arch).

- ✅ It's rolling-release, as I said, as soon as new software comes, they test it and release it. So you dont have to wait a long time to enjoy a new KDE / other fresh software.

- ✅ Great community, no toxicity

- ✅ OBS community packages, you can use `opi` or something, and it expands the package sortiment more than it already is.

- ✅ People won't think you are a Linux noob, because OpenSUSE looks cool and noone can say anything bad to you about it.

Cons:

- ❌ Slow package manager - I personally don't mind this one too much, I'd rather wait an extra 5 seconds to have a package installed than bricking my whole OS with an update.

- ❌ Tumbleweed isn't that begginer friendly, but if you're a more techy person, you'll be completely okay with it. If you want to be more safe, go for `OpenSUSE Leap`.

#### 3. Fedora

> This is a similar case to OpenSUSE. It is extremely stable, but I prefer OpenSUSE over it, because it's not a rolling release distro, meaning that you won't get the fresh out the shelf packages as quickly (Still better than Debian though).

Pros:

- ✅ Very stable; even more than Tumbleweed because of the fixed release cycle.

- ✅ Good community, lots of online threads to look up problems.

- ✅ Very begginer friendly, you won't have any problems coming from Windows nor MacOS.

Cons:

- ❌ `dnf` isn't that great, it's okay for what it is, but I prefer `pacman` or `zypper` on other distros.

- ❌ It's fixed release, you won't get fresh software right away. This is very subjective though, you may prefer stable release so the OS doesn't break as much.

#### 4. Linux Mint
> Do I need to explain myself? This one deserves a spot on here, because it's extremely stable, beginner friendly

Pros:

- ✅ Super stable

- ✅ Beginner friendly

- ✅ Intuitive

- ✅ People respect Mint users (contradictory to Ubuntu users)

Cons:

- ❌ Slow package manager (apt)
